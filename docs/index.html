Operator

This Pages app is a front-end console and learning tool. It does not run a Mythic server, does not generate real implants, and never sends your keys to a third party except the provider you choose, from your own browser.

Upstream: its-a-feature/Mythic · Docs: docs.mythic-c2.net

ATMA Assistant

Real-time streaming chat, DeepChat-style: tokens stream in as they arrive, history is saved in this browser, and you can switch model / backend without leaving the console. With a Groq key saved locally, it answers live via Groq. Via a gateway URL in Connect, it streams through your own host (Tailscale Serve recommended). Without either, it answers from the built-in demo knowledge base.
